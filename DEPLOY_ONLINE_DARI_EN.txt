AMC Doctor Search — Online deployment package

The original English page, background color (#ADEAEA), CSS, images, fonts and layout are retained.
The Excel lookup uses doctors.xlsx. The application supports /, /Verify and /verify.

LOCAL TEST (Windows)
1. Extract the ZIP.
2. Open the folder.
3. Double-click start_windows.bat.
4. Keep the black CMD window open. The browser should open at http://127.0.0.1:5000

ONLINE DEPLOYMENT (Render)
1. Create/sign in to a GitHub account and create a PRIVATE repository.
2. Upload the contents of this folder to that repository (not the ZIP file itself).
3. In Render, choose New + > Web Service and connect that repository.
4. Build command: pip install -r requirements.txt
5. Start command: gunicorn app:app
6. Deploy. Render will provide a temporary address ending in onrender.com.
7. Test both the homepage and /Verify.

Important:
- This package has not been published online yet; deployment requires access to your own hosting account.
- Use only data you are authorized to publish. The Excel file in the package is the included workbook.
- To update records, replace doctors.xlsx in the repository and redeploy.
- The current app is read-only for visitors; there is no public data-editing screen.
- A custom domain requires control of that domain and DNS settings. Do not use a domain that you do not own or have permission to configure.
